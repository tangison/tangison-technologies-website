# Tangison Hyper-Minimal Web Assets

This pack contains a cohesive visual system for Tangison Technologies.

## Visual ideology

**Vast conditions. Precise intelligence.**

Every image uses no more than one or two dominant elements. The system avoids
faces, hands, crowds, detailed machinery, fake interfaces, text, and generated
logos. The Tangison logo should be placed as a real SVG or WebP overlay in the
website rather than baked into an image.

## Folders

- `masters/` — full-resolution PNG source images
- `webp/` — compressed production-ready website images
- `mobile/` — portrait crops for key mobile placements

## Signature language

- Skeleton Coast fog, dunes, water, and mineral surfaces
- Ocean-black, fog white, mineral sand, controlled rust
- One restrained teal signal point or line
- Large negative space for live HTML typography
- Hyper-real materials rather than complex AI scenes

## Recommended implementation

- Keep all text, logos, controls, and navigation in HTML/CSS.
- Do not add heavy black overlays. Use a light gradient only where copy needs it.
- Use `object-fit: cover` and the focal positions in `asset-manifest.json`.
- Use the 1200×630 OG image for social previews.
- Use the horizontal carousel images as large editorial panels, not small cards.
- The footer should remain image-free and extremely minimal.

## Brand architecture

The visual set supports a single master idea rather than many disconnected
services. Individual images can introduce AI operations, data systems,
resilient platforms, strategy, and the Tangison ecosystem without changing the
overall brand world.
